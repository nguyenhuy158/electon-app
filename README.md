# QuickClip

Electron clipboard manager with cloud sync.

## Setup
```bash
pnpm install
cp .env.example .env
```

## Commands
- `make s`: Start app
- `make t`: Run tests
- `make l`: Lint code
- `make f`: Format code

## Architecture
Hexagonal (Domain, Application, Infrastructure).
